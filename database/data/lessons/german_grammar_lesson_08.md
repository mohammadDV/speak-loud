# German Dative Verbs & Case Question Words (A2)

Learn verbs that take a **Dative** object, fixed dative expressions, and the question words **wer / was / wen / wem**.

---

## Step 1: Verbs with Nominative and Dative

Normally a sentence has a subject (**Nominativ**) and a direct object (**Akkusativ**). Some German verbs always take a **Dative** object instead.

### Group A: Person (Nominativ) → Person (Dativ)

A person does an action directed toward another person (Dative):

| Verb | Meaning | Example |
| :--- | :--- | :--- |
| **antworten** | to answer | *Der Mann antwortet **der Frau**.* |
| **gratulieren** | to congratulate | *Die Eltern gratulieren **der Tochter**.* |
| **helfen** | to help | *Das Kind hilft **dem Mann**.* |
| **zuhören** | to listen to *(separable)* | *Die Kinder hören **der Oma** zu.* |
| **glauben** | to believe | *Ich glaube **dir**.* |
| **danken** | to thank | *Ich danke **Ihnen**.* |

> **helfen** has a stem change: *helfen* → er/sie/es **hilft**.

### Group B: Thing (Nominativ) → Person (Dativ)

The **thing** is the grammatical subject (it controls the verb). The person who experiences it is in the **Dative**:

| Verb | Meaning | Example |
| :--- | :--- | :--- |
| **schmecken** | to taste good to | *Die Torte schmeckt **der Frau**.* |
| **gefallen** | to please / to like | *Das Haus gefällt **den Leuten**.* |
| **gehören** | to belong to | *Das Auto gehört **dem Chef**.* |
| **passen** | to fit / to suit | *Die Schuhe passen **dem Mann** gut.* |
| **stehen** | to look good on | *Die Jacke steht **dem Mädchen** nicht gut.* |
| **wehtun** | to hurt *(separable)* | *Der Kopf tut **der Frau** weh.* |

### Group C: Fixed Dative Expressions

| Expression | Meaning | Examples |
| :--- | :--- | :--- |
| **Es tut [Dativ] leid.** | to be sorry | *Es tut **mir** leid.* / *Es tut **ihm** leid.* |
| **Wie geht es [Dativ]?** | How are you / is he…? | *Wie geht es **Ihnen**?* / *Es geht **ihr** schlecht.* |

## Step 2: Question Words by Case (*wer, was, wen, wem*)

| Case | People | Things |
| :--- | :--- | :--- |
| **Nominativ** (subject) | **Wer?** | **Was?** |
| **Akkusativ** (direct object) | **Wen?** | **Was?** |
| **Dativ** (indirect object) | **Wem?** | *(no bare dative “what?” — dative objects without a preposition are people)* |

Memory tip: *wer → der/er*, *wen → den/ihn*, *wem → dem/ihm*, *was → das/es*.

### Prepositions + *wen* / *wem*

The preposition decides the case:

**Dative prepositions** (*mit, bei, von, zu*) + **wem**

- ***Mit wem** gehst du ins Kino?*
- ***Bei wem** wohnst du?*
- ***Von wem** ist die Mail?*
- ***Zu wem** gehst du?*

**Accusative prepositions** (*für, ohne*) + **wen**

- ***Für wen** kaufst du das Geschenk?*
- ***Ohne wen** willst du nicht Urlaub machen?*

## Step 3: Useful Contrasts

| Accusative verb | Dative verb |
| :--- | :--- |
| *Der Chef **fragt** die Assistentin.* | *Die Assistentin **antwortet** dem Chef.* |
| *Der Mann **schenkt** der Frau Blumen.* | *Die Blumen **gefallen** der Frau.* |
| *Der Kellner **serviert** den Gästen das Essen.* | *Das Essen **schmeckt** den Gästen.* |
| *Die Eltern **schenken** dem Sohn ein Auto.* | *Das Auto **gehört** dem Sohn.* |

Always add **-n** in **Dative plural**: *den Leuten*, *den Freunden*, *den Gästen*.
