# German Cases, Pronouns & Sentence Structure: Step-by-Step Guide (A1/A2)

Learn the **accusative** and **dative** cases, **personal pronouns** in all cases, and **word order with objects**.

---

## Step 1: The Accusative Case (*Akkusativ*)

A sentence typically has a **subject** (nominative — who does the action) and a **direct object** (accusative — who/what receives the action).

* **Example:** *Der Kellner (nominative / subject) trinkt **einen Saft** (accusative / direct object).*
* **Question words:**
  * People: **Wen?** (Whom?) — *Wen sehen Sie? Meine Kollegen.*
  * Things: **Was?** (What?) — *Was trinken Sie gerne? Champagner.*

### Key Rule for Articles in Accusative
**Only masculine nouns change** in the accusative. Neuter, feminine, and plural stay the same as nominative.

| Gender | Nominative | **Accusative** |
| :--- | :--- | :--- |
| **Masculine** (*der*) | der / ein / kein Mann | **den / einen / keinen** Mann |
| **Neuter** (*das*) | das / ein / kein Kind | das / ein / kein Kind |
| **Feminine** (*die*) | die / eine / keine Frau | die / eine / keine Frau |
| **Plural** (*die*) | die / – / keine Leute | die / – / keine Leute |

> **Note:** Possessives (*mein, dein, sein…*) take the same endings as *kein*: *Ich liebe **meinen** Mann.*

---

## Step 2: The Dative Case (*Dativ*)

The dative is used for the **indirect object** (usually the person who receives something) and after dative prepositions such as **mit**, **zu**, **bei**, and **nach**.

* **Question word (person):** **Wem?** (To whom?)

### Key Rules for Dative
1. **Masculine and neuter are identical:** **dem / einem / keinem**.
2. **Feminine ends in *-r*:** **der / einer / keiner**.
3. **Plural:** article **den / – / keinen**, and the noun usually adds **-n** (*den Leute**n***, *mit zwei Kinder**n***).
   * *Exception:* plurals that already end in **-n** or **-s** do not get another *-n* (*mit zwei Autos*, *den Frauen*).

| Gender | Nominative | Accusative | **Dative** |
| :--- | :--- | :--- | :--- |
| **Masculine** | der / ein / kein Mann | den / einen / keinen Mann | **dem / einem / keinem** Mann |
| **Neuter** | das / ein / kein Kind | das / ein / kein Kind | **dem / einem / keinem** Kind |
| **Feminine** | die / eine / keine Frau | die / eine / keine Frau | **der / einer / keiner** Frau |
| **Plural** | die / – / keine Leute | die / – / keine Leute | **den / – / keinen** Leute**n** |

---

## Step 3: Personal Pronouns (*Personalpronomen*)

3rd-person pronouns often match the definite articles (*der → er*, *den → ihn*, *dem → ihm*).

| Nominative (Subject) | Accusative (Direct Object) | Dative (Indirect Object) |
| :--- | :--- | :--- |
| **ich** *(I)* | **mich** *(me)* | **mir** *(to me)* |
| **du** *(you)* | **dich** *(you)* | **dir** *(to you)* |
| **er** *(he / der)* | **ihn** *(him / it)* | **ihm** *(to him / it)* |
| **sie** *(she / die)* | **sie** *(her / it)* | **ihr** *(to her / it)* |
| **es** *(it / das)* | **es** *(it)* | **ihm** *(to it)* |
| **wir** *(we)* | **uns** *(us)* | **uns** *(to us)* |
| **ihr** *(you pl.)* | **euch** *(you pl.)* | **euch** *(to you pl.)* |
| **sie** *(they)* | **sie** *(them)* | **ihnen** *(to them)* |
| **Sie** *(You formal)* | **Sie** *(You formal)* | **Ihnen** *(to You formal)* |

### Common Dative Verbs
Some verbs take a **dative** person even without a second object:
* **helfen** — *ich helfe **dir***
* **antworten** — *ich antworte **dir***
* **gefallen** — *du gefällst **mir***
* **passen** — *das passt **mir***
* **gehen** — *Wie geht es **Ihnen**? Es geht **mir** gut.*

## Step 4: Verb Types & Word Order with Objects

### 1. Three Main Verb Categories
1. **Intransitive (nominative only):** *Der Mann **lacht**.* Also: *kommen, wohnen, schlafen, gehen, sein*.
2. **Transitive (nominative + accusative):** *Der Kellner **trinkt** einen Saft.* Also: *essen, lesen, treffen, lieben, besuchen, haben, möchten, finden*.
3. **Ditransitive (nominative + dative person + accusative thing):** *Der Kellner **bringt** dem Mann den Fisch.* Also: *schenken, kaufen, servieren, verkaufen, geben, zeigen*.

### 2. Word Order for Two Noun Objects
With **two noun objects**, the **dative (person) comes before the accusative (thing)**:
* *Die Kellnerin serviert **den Leuten** (Dat.) **die Getränke** (Akk.).*
* *Heute bringt der Chef **den Gästen** (Dat.) **das Frühstück** (Akk.).*

---

## Step 5: Useful Example Sentences

### Accusative
* Ich brauche **den** Stift.
* Ich trinke **das** Glas Wein.
* Wir sehen **den** Film.
* Ich habe **keinen** Tisch, aber **ein** Handy.

### Dative
* Ich fahre **mit dem** Auto.
* Ich gehe **mit einer** Freundin ins Kino.
* Er hilft **den Kindern**.
* Das Buch gefällt **mir**.

### Pronouns
* Siehst du **ihn**? (der Mann → ihn)
* Ich helfe **dir**.
* Es geht **mir** gut. / Wie geht es **Ihnen**?
* Er bringt **ihr** den Tee.

### Dat before Akk
* Der Vater kauft **dem Sohn** **einen Computer**.
* Die Mutter schenkt **der Tochter** **ein Handy**.
* Wir zeigen **den Gästen** **das Haus**.
