# German Prepositions (Time & Place): Step-by-Step Guide (A1/A2)

Learn **temporal prepositions**, **dative-only** and **accusative-only (FUDOG)** prepositions, **two-way prepositions** (*Wechselpräpositionen*), and the **Wohin? / Wo? / Woher?** system.

---

## Step 1: Temporal Prepositions (Time)

| Preposition | When to use it | Examples |
| :--- | :--- | :--- |
| **–** *(none)* | Years, *letzten Monat*, *nächstes Jahr* | **1997**, **2025**, letzten Monat |
| **im** *(in + dem)* | Seasons, months | **im** Sommer, **im** Januar |
| **am** *(an + dem)* | Days of the week, times of day (except night), dates | **am** Montag, **am** Morgen, **am** 12.5. |
| **in der** | Night (exception) | **in der** Nacht |
| **um** | Clock times, midnight | **um** 9.00 Uhr, **um** Mitternacht |
| **bis (zum)** | Until / end point | **bis** morgen, **bis zum** Abend |
| **ab / von … an** | From … on (future / from now) | **Ab** morgen, **Von** heute **an** |
| **seit** | Since / for (+ Dative; started in the past, still true) | **seit** drei Monaten |
| **vor / nach** | Before / after (+ Dative) | **vor** der Arbeit, **nach** dem Essen |
| **zwischen** | Between two times (+ Dative) | **zwischen** 5 und 7 Uhr |
| **von … bis (zum)** | From X to Y | **von** Montag **bis** Freitag |

---

## Step 2: Prepositions Always with Dative

These seven always take the **dative**: **aus, bei, mit, nach, seit, von, zu**.

### Common contractions
* **bei + dem = beim** · **von + dem = vom** · **zu + dem = zum** · **zu + der = zur**

### Meanings
1. **aus** (*from / out of*): *Er geht **aus dem** Haus.* · *Der Stuhl ist **aus** Metall.*
2. **bei** (*at / with / near*): *Ich bin **bei** Lisa.* · *Er arbeitet **bei** Siemens.* · *Augsburg liegt **bei** München.*
3. **mit** (*with / by*): *Ich tanze **mit meinem** Freund.* · *Wir fahren **mit dem** Bus.*
4. **nach** (*to / after*): cities & countries **without** an article — *Er fährt **nach** Hamburg.* · time: ***Nach** dem* Essen…
5. **seit** (*since / for*): *Ich wohne **seit einem** Jahr in Berlin.*
6. **von** (*from / of*): *Ich komme **vom** Zahnarzt.* · *Die Schwester **von meiner** Freundin.*
7. **zu** (*to*): *Ich gehe **zum** Bahnhof / **zu meinen** Eltern / **zum** Frühstück.*

## Step 3: Prepositions Always with Accusative (FUDOG)

| Letter | Preposition | Meaning | Example |
| :--- | :--- | :--- | :--- |
| **F** | **für** | for | *Der Fisch ist **für dich**.* |
| **U** | **um** | around / at (time) | *Sie geht **um den** Tisch.* |
| **D** | **durch** | through | *Er geht **durch den** Park.* |
| **O** | **ohne** | without (often no article) | *Kaffee **ohne** Zucker.* |
| **G** | **gegen** | against | *Das Auto fährt **gegen den** Baum.* |

---

## Step 4: Two-Way Prepositions (*Wechselpräpositionen*)

Nine prepositions can take **dative or accusative**:
**in, an, auf, vor, hinter, über, unter, neben, zwischen**

| Question | Meaning | Case | Example |
| :--- | :--- | :--- | :--- |
| **Wo?** | Static location | **Dative** | *Die Vase steht **auf dem** Tisch.* |
| **Wohin?** | Movement toward | **Accusative** | *Sie stellt die Vase **auf den** Tisch.* |

Contractions: **im** / **am** (Dat.) · **ins** / **ans** (Akk.)

### Position verb pairs
* **liegen** (*Wo?* + Dat.) ↔ **legen** (*Wohin?* + Akk.)
* **stehen** (*Wo?* + Dat.) ↔ **stellen** (*Wohin?* + Akk.)
* **sitzen** (*Wo?* + Dat.) ↔ **setzen** (*Wohin?* + Akk.)

---

## Step 5: Local Matrix (*Wohin? / Wo? / Woher?*)

| Location type | **Wohin?** | **Wo?** | **Woher?** |
| :--- | :--- | :--- | :--- |
| Cities & countries (no article) | **nach** | **in** | **aus** |
| Countries with article, rooms, enclosed places | **in** + Akk. | **in** + Dat. | **aus** + Dat. |
| Vertical edge / water / screen | **an** + Akk. | **an** + Dat. | **von** + Dat. |
| Horizontal surface | **auf** + Akk. | **auf** + Dat. | **von** + Dat. |
| People, activities, companies | **zu** + Dat. | **bei** + Dat. | **von** + Dat. |

> **Home:** *nach Hause* (Wohin?) · *zu Hause* (Wo?) · *von zu Hause* (Woher?)

---

## Step 6: Useful Examples

### Time
* **Im** Sommer fahren wir nach Italien.
* Wir treffen uns **am** Montag **um** 10 Uhr.
* Ich wohne **seit** zwei Jahren hier.
* **Nach** dem Essen gehen wir spazieren.

### Dative / Accusative prepositions
* Ich fahre **mit dem** Bus **zum** Bahnhof.
* Der Brief ist **für dich**.
* Wir gehen **durch den** Park.

### Wo? vs Wohin?
* Das Buch liegt **auf dem** Tisch. *(Wo?)*
* Ich lege das Buch **auf den** Tisch. *(Wohin?)*

### Local system
* Ich fahre **nach** Berlin. / Ich bin **in** Berlin. / Ich komme **aus** Berlin.
* Ich gehe **ins** Kino. / Ich bin **im** Kino. / Ich komme **aus dem** Kino.
* Ich gehe **zum** Arzt. / Ich bin **beim** Arzt. / Ich komme **vom** Arzt.
* Ich gehe **nach Hause**. / Ich bin **zu Hause**. / Ich komme **von zu Hause**.
