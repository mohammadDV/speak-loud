# German Grammar: Talking About the Past (*Perfekt* & *Präteritum*) (A2)

Learn how to form the **Perfekt**, choose **haben** or **sein**, build the **Partizip Perfekt**, and know when Germans prefer the **Präteritum**.

---

## Step 1: Introduction to the *Perfekt*

In spoken German, the **Perfekt** is the most common way to talk about the past (*gestern*, *vor einer Stunde*, *letztes Jahr*).

### How to form it

You need two parts:

1. **Auxiliary verb (position 2):** conjugated **haben** or **sein**
2. **Partizip Perfekt (end of the sentence):** the past participle of the main verb

| Example | Meaning |
| :--- | :--- |
| *Ich **habe** zehn Stunden **gearbeitet**.* | I worked for ten hours. |
| ***Hast** du auch Tennis **gespielt**?* | Did you also play tennis? |
| *Ich **bin** zur Arbeit **gegangen**.* | I went to work. |

---

## Step 2: *Perfekt* with *haben* vs. *sein*

Most verbs use **haben**. A smaller group uses **sein**.

### Use *sein* for:

1. **Change of place (movement from A to B)**

| Infinitive | Example |
| :--- | :--- |
| *gehen* | *Ich **bin** zur Arbeit **gegangen**.* |
| *fahren* | *Wir **sind** mit dem Taxi **gefahren**.* |
| *fliegen*, *kommen*, *laufen*, *fallen*, *einsteigen*, *aussteigen* | movement A → B |

2. **Change of state (transition from A to B)**

| Infinitive | Example |
| :--- | :--- |
| *aufwachen* | *Ich **bin** **aufgewacht**.* |
| *einschlafen* | *Ich **bin** **eingeschlafen**.* |
| *werden*, *passieren*, *sterben*, *wachsen* | state change |

3. **Two important exceptions (no movement, but still *sein*)**

| Infinitive | Example |
| :--- | :--- |
| *sein* | *Ich **bin** zu spät **gewesen**.* |
| *bleiben* | *Wir **sind** drei Stunden **geblieben**.* |

Everything else (most activities, objects, talking, eating, working…) uses **haben**.

---

## Step 3: Forming the *Partizip Perfekt*

How you build the past participle depends on the verb type.

### 1. Regular verbs (*regelmäßige Verben*)

Formula: **ge- + stem + -t**

| Infinitive | Partizip |
| :--- | :--- |
| *kaufen* | **gekauft** |
| *arbeiten* | **gearbeitet** *(adds -e- for pronunciation)* |
| *spielen* | **gespielt** |

### 2. Irregular verbs (*unregelmäßige Verben*)

Formula: **ge- + stem (often with vowel change) + -en**

| Infinitive | Partizip |
| :--- | :--- |
| *schlafen* | **geschlafen** |
| *nehmen* | **genommen** |
| *trinken* | **getrunken** |
| *sehen* | **gesehen** |
| *treffen* | **getroffen** |

### 3. Separable verbs (*trennbare Verben*)

**-ge-** goes *between* the prefix and the verb stem:

| Infinitive | Partizip |
| :--- | :--- |
| *einkaufen* | **eingekauft** |
| *aufstehen* | **aufgestanden** |
| *zurückkommen* | **zurückgekommen** |

### 4. Inseparable verbs (*untrennbare Verben*)

Prefixes **be-, emp-, ent-, er-, ge-, ver-, zer-** → **no ge-**

| Infinitive | Partizip |
| :--- | :--- |
| *verstehen* | **verstanden** |
| *besuchen* | **besucht** |
| *erklären* | **erklärt** |
| *besichtigen* | **besichtigt** |

### 5. Verbs ending in *-ieren*

No **ge-**. They end in **-t**.

| Infinitive | Partizip |
| :--- | :--- |
| *telefonieren* | **telefoniert** |
| *studieren* | **studiert** |
| *probieren* | **probiert** |

### 6. Mixed verbs (*Mischverben*)

Vowel change like irregular verbs, but ending **-t** like regular verbs.

| Infinitive | Partizip |
| :--- | :--- |
| *denken* | **gedacht** |
| *bringen* | **gebracht** |
| *kennen* | **gekannt** |
| *wissen* | **gewusst** |

---

## Step 4: *Perfekt* vs. *Präteritum*

For almost all verbs, spoken German prefers **Perfekt**. For a few verbs, Germans prefer **Präteritum** even when speaking:

> **Rule:** For **sein**, **haben**, and **modal verbs** (*müssen, können, wollen, dürfen, sollen*), use the **Präteritum**.

| Infinitive | Präsens | Präteritum |
| :--- | :--- | :--- |
| **sein** | ich bin | **ich war** |
| **haben** | ich habe | **ich hatte** |
| **müssen** | ich muss | **ich musste** |
| **können** | ich kann | **ich konnte** |
| **wollen** | ich will | **ich wollte** |
| **dürfen** | ich darf | **ich durfte** |
| **sollen** | ich soll | **ich sollte** |

Also common in *Präteritum*: *geben* → **es gab**, *wissen* → **ich wusste**, *brauchen* → **wir brauchten**.

### Quick contrast

| Prefer *Präteritum* | Prefer *Perfekt* |
| :--- | :--- |
| *Gestern **war** ich bei Freunden.* | *Gestern **habe** ich Tennis **gespielt**.* |
| *Ich **wollte** helfen.* | *Ich **bin** nach Hause **gegangen**.* |
| *Wir **mussten** viele Möbel tragen.* | *Sie **haben** ein Haus **gekauft**.* |
